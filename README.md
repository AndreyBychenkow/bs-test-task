# Мини-синхронизатор заявок

Сервис забирает «сырые» заявки из источника, нормализует телефоны, удаляет дубли
и отдаёт итоговый отчёт по публичному URL.

**🔗 Живой эндпоинт:** https://bs-test-task.onrender.com/result

## Что делает

1. **Забирает заявки** из `https://test.ooobs.ru/api/orders` (настраивается через `SOURCE_URL`).
2. **Нормализует телефоны** к формату `+7XXXXXXXXXX`:
   - `+7 999 123-45-67`, `8 (999) 123 45 67`, `79991234567`, `8-916-000-00-01` → корректные номера;
   - 10 цифр без кода (`9005551212`) → `+79005551212`;
   - всё, что не приводится к 11 цифрам (`123`, `не указан`, `+7 999`, пустое) → **отбрасывается**.
3. **Дедуплицирует по телефону:** остаётся запись с **максимальным `amount`**;
   при равных суммах — **более поздняя по `created_at`** (тай-брейк — больший `id`).
4. **Отдаёт JSON** строго по схеме задания с блоком `stats`.
5. **Идемпотентность:** результат детерминированно пересчитывается из источника,
   повторные запуски не плодят дубли — повторный `GET /result` даёт тот же JSON
   (кэш 30 сек, `GET /sync` — принудительная синхронизация).

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/result` | итоговый JSON (то, что сдаётся) |
| GET | `/` | то же самое |
| GET | `/sync` | принудительный ресинк из источника |
| GET | `/health` | статус: время последнего синка, доступность источника |

## Результат на текущих данных

```json
{
  "clients": [ ... 8 клиентов ... ],
  "stats": {
    "received": 17,
    "unique": 8,
    "duplicates_merged": 5,
    "invalid_dropped": 4
  }
}
```

## Стек и запуск

Python 3.12 + FastAPI + httpx. Деплой — Docker на Render (`render.yaml` / `Dockerfile`).

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
# тесты
python tests/test_sync.py
```

## Секреты

Источник публичный — секретов в коде нет. Всё настраивается через переменные
окружения (`SOURCE_URL`, `CACHE_TTL`, `KEEPALIVE_MINUTES`) — задаются в Render
Dashboard, не хранятся в репозитории.
